File Format

Format: EDF/TXT/CSV
Rate: 250 Hz
Channels: F3, F4, O1, O2, GND, REF
Optional: 7th column for timestamp
Delimiter: Space, comma, or tab
Comments: # or // are ignored

Signal Quality Tips

  • Good signal: RMS 5-100 μV
  • Quality: SNR 0-10 dB - bad signal (noise); 10-20 dB - good; 20-40 dB - perfect
  • Avoid saturation: Below ±100 μV
  • Filter first: Apply bandpass filter in the range 1-30 Hz before analysis
  • Alpha peak: 8-12 Hz in O1/O2
